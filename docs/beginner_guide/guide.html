1. 一张图看懂整个项目

一句话：头上戴摄像头录自己的手 → 认出手指在哪、离镜头多远 → 扔掉坏片段 → 打包成训练数据 → 教机器人学你怎么动手。

绿：软件已能跑 黄：部分完成 红：等硬件或更多数据
当前状态：软件链路大体就绪；双目头戴还没做出来；临时用 iPhone Pro + 激光雷达；小模型还没超过「手永远不动」基线——主要因为数据太少。
步骤类比仓库里叫什么
录像拍你切菜采集（头戴 / iPhone / EgoDex / HOT3D）
认手标出每根手指WiLoR 手部姿态
量距离量出菜离镜头多远双目三角化 或 iPhone LiDAR
挑好片段剪掉糊片、干等QC 质检
打包做成标准课件LeRobot 数据集
教机器人看视频学动作模仿学习（ACT / 线性 BC）
换身体人手动作改编给机械臂仿真重定向 retarget

论文三条路径（docs/iphone_arxiv_plan.md）：

  • 路径 A：先证明管线能训出「还能用」的策略
  • 路径 B：讲清楚数据质量（双目 / LiDAR / 单目差在哪）
  • 路径 C：预训练是否真的涨分

3. 数据之旅：跟一帧画面走一遍

假设你在桌前抓起杯子。看第 42 帧发生了什么：

类比：observation =「现在手在哪」；action =「下一步挪多少」。机器人学的是：看到这个画面，手该怎么动。
字段样子（示意）人话
21 个关节每个点 (x,y,z)，单位米手指骨架的 3D 位置
手腕 6DoFxyz + 四元数 (qx,qy,qz,qw)手腕在哪、朝向哪
置信度0.92模型有多确信；低于 0.5 常当无效
action下一帧手腕增量下一小步手要怎么动
action_valid(1, 0)左有效、右无效；别把缺测当「保持不动」学

字段定义见 scripts/egodata/schema.py（版本 1.0，21 点顺序与 MediaPipe Hands 一致）。

4. 流水线每一站（卡片）

1采集：把世界录进文件夹

做什么：把头戴 / iPhone / 公开数据变成「会话目录」。
类比：原材料放进标好标签的周转箱。

脚本：simulate_device_session.py · iphone/record3d_adapter.py · iphone/mcap_adapter.py

python scripts/validate_session.py /path/to/session

2认手：WiLoR

做什么：在彩色图上找出左右手 21 个关节点。
类比：在照片上用笔勾出骨骼。

实现：scripts/headcam/hand_pose.py（管线自动调用）· 后端默认 wilor

EgoDex 上：WiLoR 检出约 95%、关节误差约 3.5 cm；MediaPipe 约 50% / 8 cm。

3量距离：双目 或 激光雷达

做什么：把画面上的点变成真实厘米。
类比：两只眼睛看深度，或用激光尺直接量。

双目：headcam/stereo_pipeline.py · iPhone：headcam/rgbd_pipeline.py

HOT3D 双目手腕中位约 1.2 cm；iPhone LiDAR 代理约 1.5 cm；单目绝对手腕可差到约 22 cm。

4平滑与补洞

做什么：抖一下抹平；短缺口插值。
类比：给轨迹上蜡，小坑填平。

scripts/headcam/hand_track_refine.py · 补帧标 filled，训练里 action_valid=0

5质检 QC

做什么：扔掉手出画、视线飘、糊、干等太久的片段。
类比：挑出拍糊了的镜头，不进教材。

python scripts/egodata_qc.py \
  --episodes outputs/egodex_unified \
  --html outputs/yield_report.html \
  --csv outputs/yield_episodes.csv

6打包成 LeRobot

做什么：只导出 QC 通过的片段；动作是「手腕下一步怎么动」。
类比：把剪好的镜头排成标准课件。

python scripts/ego_to_lerobot.py \
  --episodes outputs/egodex_unified \
  --yield-csv outputs/yield_episodes.csv \
  --out outputs/egodex_lerobot \
  --horizon 16 --video-size 224

7训练：线性 BC / ACT

做什么：让模型看状态/图像，预测动作。
类比：学生看示范，学下一秒手怎么动。

python scripts/ego_pretrain_bc.py \
  --dataset outputs/egodex_lerobot \
  --max-frames 1000 \
  --log outputs/ego_pretrain.log

ACT：scripts/ego_act_train.py / notebooks/egodex_act_scaling_colab.ipynb

★一条命令总入口（最常用）

# HOT3D 公开双目
python scripts/run_stereo_pipeline.py \
  --hot3d data/train_quest3/clip-000000 --out outputs/hot3d

条形按 3 cm 满格比例绘制。越小越好。目标 ≤ 2 cm。

5.3 小模型训得怎样？

诚实结论：数据太少时，线性 BC / 小 MLP / 小 ACT 还没稳定赢过「手永远不动」。 类比：只看 3 集电视剧就想学会炒菜——不如站着不动偶尔碰巧像样。
实验零动作 ADE模型人话
EgoDex 图像 ACT（4 任务子集）3.13 cmACT ~3.06–3.17几乎打平
HOT3D 4 段（596 帧）4.37 cm线性/MLP 更差或持平帧数不够
iPhone 3 段 Path A~8.4 cm线性/MLP 更差先证明管线通，再堆数据

5.4 仿真重定向（简述）

人手腕 → 6 轴臂抓放（docs/retarget_sim.md）：合成开环 20/20 很好；真实 EgoDex 刚性约 15/101；行为克隆仍弱。「映射过去」≠「学会策略」。

8. 接下来做什么

  1. 继续用 iPhone 采更多段（Path A）：目标 10+ 段，再跑 iphone_train_compare.py，看能否压过零动作。
  2. 补全 Path B 质量图：mono vs LiDAR 直方图、更多有深度片段。
  3. 买齐 / 装好双目头戴（方案 A 约 727–982 元）：基线 8–10 cm，镜头约 100°。见 docs/headcam_stereo_bom.md。
  4. 到货第一天：按 docs/hardware_day1_checklist.md —— 同步 → 标定 → 首段 → validate_session → run_stereo_pipeline。
  5. 自采手腕误差填进进度表（目标 ≤ 2 cm，现在「待补」）。
  6. 数据够了再上 ACT 与预训练对比（Path C）。
